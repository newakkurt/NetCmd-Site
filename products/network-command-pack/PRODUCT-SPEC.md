## Planned deliverables
- Three vendor-specific command reference PDFs (TR and EN).

- Read-only operational audit command checklist.
- Troubleshooting quick-reference: interface, VLAN, STP, routing, DHCP, ARP/MAC, SNMP and logs.
- README explaining supported families, safe lab validation and update policy.

## Quality requirements
- Do not label commands universal across AOS-S and AOS-CX; identify platform family.
- Separate read-only commands from configuration-changing commands.
- Mark disruptive commands and require lab validation before production use.
- Include tested model/software notes only when actually tested; otherwise mark as unverified.
- TR and EN must carry equivalent technical meaning.
